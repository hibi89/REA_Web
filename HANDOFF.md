## Key engineering changes, rollback and limitations
D7 demonstrated race-created empty owner directory could be replaced by generic Linux os.rename. Fixed with Linux renameat2(RENAME_NOREPLACE) and Windows no-replace directory rename; macOS/unsupported OS fails closed. Existing ZIP publication exposed incomplete file via stream copy: now verify in temp then atomically os.link complete archive into destination; unsupported filesystem hardlinks fail closed. Staging exceptions, symlinks, owner collisions and corrupted ZIP are negative-tested without touching owner data. Generated SQLite mode=ro + query_only; JSON summary source label fixed, formula-looking cells displayed with DOM textContent and no dialogs. **No spreadsheet CSV/XLSX export:** if added, formula injection must be mitigated. Abrupt full power loss, fsync and real customer backup/restoration or malicious filesystem actor NOT_RUN. app/data.sqlite contains actual user rows, so not PII-free.
D3 earlier Windows launcher py -3 failed then fixed to PATH python. D6 first Windows vendor SHA failed due to Git CRLF, fixed by core.autocrlf false before pinned checkouts. All tests after repairs green.
