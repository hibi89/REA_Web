# REA_Web — Web Analysis & Independent App Reconstruction

**Status: PROJECT BOOTSTRAP / NOT A COMPLETE PRODUCT (2026-10-25)**

REA_Web combines Fable 5.1 website analysis evidence with Astra Web Catcher observation/specification and independent application rebuilding. Authorized sources and customer-provided CSV/Excel-first data only; no unauthorized cloning, private API access, production database changes, or open-ended collection.

**Architecture principle:** preserve the Fable and Astra originals; import version-pinned snapshots on isolated branches, create an evidence-to-spec adapter and reproducible synthetic tests, then gate integration behind review.
