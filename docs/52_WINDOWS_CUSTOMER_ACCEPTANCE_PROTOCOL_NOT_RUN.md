# Windows 고객 인수검수 절차 — NOT_RUN

**상태: NOT_RUN.** 이 양식은 일반 사용자의 실제 시험 기록이 아니다. 서명/날짜를 임의로 채우거나 개발자가 수행한 자동 검증을 사람 검수로 바꾸어 기록하지 않는다. 개인정보·고객 자료 대신 압축 파일에 포함된 합성 데이터만 사용한다.

- Python/py.exe 버전 및 발견 상태: ____________________
- 검수 ZIP 이름과 SHA-256: ____________________
- 브라우저/버전: ____________________
- 실제 고객 파일/개인정보를 사용하지 않았음: [ ] 확인

수행자에게 ZIP, README_KO.md, 생성 앱 안내서만 제공하고 먼저 사용법을 설명하지 않는다. 막히면 화면 문구와 소요 시간을 기록하고 결과를 PASS/FAIL/BLOCKED/NOT_RUN 중 하나로 남긴다. 관리자 권한 요구, 방화벽 해제, 보안 설정 완화 요구 시 중단한다.
