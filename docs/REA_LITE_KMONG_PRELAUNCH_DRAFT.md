## 상품명 후보

**REA Lite | CSV 데이터를 설치 없이 열어보는 오프라인 HTML 카탈로그**

## 고객용 상품 설명 초안

보유하신 상품·재고·목록 데이터를 **한 개의 오프라인 HTML 파일**로 정리해 드리는 서비스입니다.
Chrome 또는 Edge에서 파일을 열면 검색, 카테고리 필터, 정렬, 항목 상세 보기를 사용할 수 있습니다.
인터넷 계정이나 월 구독료, 별도 서버는 필요하지 않습니다.

처음 생성된 HTML은 변경되지 않습니다. 이후 **같은 열 구성의 UTF-8 CSV**를 선택하고 검증 후 적용하면 화면의 데이터를 갱신할 수 있습니다. 변경 내용을 계속 보관하려면 **새 HTML 파일을 직접 다운로드**해야 합니다.

선택 가능한 기본 테마는 카페·재고관리·사무실 세 가지입니다. 실제 고객 PC에서 검수 및 상품화 승인 전까지는 판매하지 않습니다.

## 안전한 작업 흐름 초안

1. 고객이 데이터 원천 권한과 비민감정보 여부를 확인한다. 판매자가 실제 자료를 받을지는 별도 승인으로 정한다.
2. 판매자는 `rea.mvp` 실제 파서로 스키마·행 수·중복 ID를 검증한다.
3. 필요한 경우 고객 확인을 받은 정확한 필드 매핑을 사용한다.
4. 승인한 원본 파일의 SHA-256을 고정하고 `APPROVE`를 확인한 뒤 새 경로에만 HTML을 생성한다.
5. 검증 결과·완성 HTML을 확인하고 전송 권한 범위 내에서만 납품한다. 원본 데이터의 보관·삭제는 합의된 조건에 따른다.
6. 수정 요청은 약정한 범위 안에서 수행한다. 별도 합의 없이는 기존 파일을 덮어쓰지 않는다.
