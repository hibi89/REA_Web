## 2. Lite 가격 3안 — 개발된 동일 코드의 작업 범위만 구분

| 항목 | BASIC | STANDARD (우선 검토) | PREMIUM |
| --- | --- | --- | --- |
| **가격 제안** | **29,000원** | **49,000원** | **79,000원** |
| 입력 | 사전에 올바른 스키마로 정리된 CSV 1개 | CSV 1개 또는 평면 문자열 JSON 1개 | CSV 1개 또는 평면 문자열 JSON 1개 |
| 스키마 | `id,title,category` 필드 기존 존재 | 필수 3필드에 대한 고객 승인 1:1 매핑 가능 | STANDARD와 동일 |
| 행 수 상한(상품 약속안) | 500 | 3,000 | 10,000 |
| 최대 필드 수 | 8 | 15 | 20 |
| 테마 | 3가지 중 1개 선택 | 3가지 중 1개 선택 | 3가지 중 1개 선택 |
| 고객 납품물 | HTML 1개, 사용 안내 | HTML 1개, 사용 안내, 검수 메모 초안 | HTML 1개, 사용 안내, 검수 메모 + CSV 갱신 방법 설명 |
| 고객 CSV 직접 갱신 | 동일 열/순서의 CSV만 지원 | 동일 | 동일 |
| 단순 수정 | **미확정** (1회 제안) | **미확정** (1회 제안) | **미확정** (2회 제안) |
| 납기 | **미확정** | **미확정** | **미확정** |

이 차이는 기능 차이가 아니라 **판매자가 검증·필드 승인·안내에 투입하는 작업 범위** 차이이다. 상품 구간의 행·열 상한은 원래 코드의 하드 제한(10MiB, 최대 10,000행/20열/셀당 2,000자)을 절대 초과하지 않는다. 행·열 상한은 계약상 선택 범위이고, 코드 제한값은 아니다.

**판매 시작 추천:** 29,000원은 형식이 이미 올바른 작은 CSV에만 허용하고, 49,000원을 기본 추천 등급으로 둔다. 79,000원은 운영상 요청이 많은 고객에 한해 제한적으로 제시한다. 원가·실제 수작업 시간/검수 결과가 없는 현재는 모두 **가격 가설**이다. 가격 변경은 사용자 승인 후에만 한다.

## 3. 명확히 제외해야 할 기능

- 원본 CSV/JSON을 자동 분석하여 적절한 ID·제목·카테고리를 추론해 확정하는 작업
- 고객이 직접 브라우저에서 JSON을 재업로드하여 갱신하는 기능 (직접 갱신은 동일 스키마의 CSV 전용)
- XLSX 원본 직접 지원 (엑셀에서 CSV로 올바르게 내보내는 것은 별도 작업)

- 고객 DB·고객 개인정보 처리, 이미지/로고 권리 확인 대행, 무제한 수정
- Lite의 가격안과 Pro 299,000원 서버형 앱 범위를 혼합한 판매 주장
