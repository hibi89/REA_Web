# 크몽 상품 초안 — 고객 데이터 기반 로컬 웹앱 제작

**목표 가격: 299,000원. 판매 승인 전 초안이며 지금 주문을 받지 않는다.** 실제 사람의 Windows 검수, 고객 권리 확인, 재배포 라이선스, 개인정보·보안·백업 검토와 계약/환불/지원 조건이 확인되기 전에는 게시하지 않는다.

## 기술적으로 구현된 범위

- 고객이 제공하고 사용할 권리가 있는 UTF-8 CSV 1개 또는 flat JSON 배열 1개.
- 두 파일은 현재 툴에서 각 파일의 명시적 승인과 동일 스키마 확인을 거쳐 **ROW APPEND**할 수 있다. 합계 최대 10 MiB 및 10,000행, 20열 제한을 지킨다. 자동 JOIN이나 서로 다른 테이블 관계 매핑은 없다.
- 한 페이지 로컬 웹앱과 신규 SQLite: 목록, 검색, 카테고리 필터, 상세 조회. 기능은 읽기 전용이다.
- Windows 납품 ZIP, 무결성 사전검사, Python 실행기, 한국어 실행/복구 안내와 고객 자체 검수 체크리스트.
- 별도 실험 코드에는 고객이 제공한 Fable 관찰 기록 JSON을 오프라인 검토하는 기능이 있으나 URL 접속이나 웹사이트 크롤링은 하지 않는다. Fable/Astra 권리와 검수가 미승인이라 현재 상품 범위·가격안에서는 제외한다. 결과를 고객 CSV 필드에 연결하거나 자동 승인하지 않는다.

기술 구현 상한은 거래상 포함 범위가 아니다. 실제 계약에는 데이터 스키마, 파일 수, 행·열·용량, 선택할 기능, Windows 지원 범위를 별도로 적고 그 계약 범위에서만 납품한다. 현재 앱은 한 페이지이며 “2개 화면”을 약속하지 않는다.

## 가격안에 포함하려는 항목 (미승인)

- 사전 합의한 비민감 고객 데이터 입력과 명시적 필드 매핑 확인
- 목록/검색/필터/상세 중 합의한 최대 3개 단순 기능
- 독립형 로컬 앱, ZIP, Windows 한국어 안내 및 검수 체크리스트
- 최초 합의 기준의 결함 수정 1회 묶음. 신규 기능·데이터 정제·범위 변경은 포함하지 않는다.

299,000원, 소요시간, 수정 기간, 취소/환불, 지원 창구는 가설이다. 크몽 최신 정책과 실제 수작업 시험을 확인하고 계약 문구를 승인한 뒤에만 게시할 수 있다.

## 제외 범위

크롤링·데이터 수집 대행, 무허가 사이트·데이터 사용, 다른 스키마 간 JOIN, 실 DB/API 연결, 사용자 계정/권한, 결제, CRUD 편집, 외부 공개 호스팅, 배포·운영, 보안 인증, 민감정보 처리, 무제한 수정과 장기 유지보수는 제공하지 않는다.

## 검수 체크

고객은 별도 `ACCEPTANCE_CHECKLIST.md`에 따라 목록 수, 검색, 카테고리, 상세 보기, 종료·재실행 후 데이터 유지 여부를 자신의 비민감 자료로 확인한다. 실제 수행되지 않은 항목은 비워 둔다. 해당 체크리스트는 고객 동의, 법적 권리, 보안 적합성, 상용 승인을 대체하지 않는다.
