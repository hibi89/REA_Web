# REA WEB Lite 고객 사용안내 초안 (한국어)
**검수용 문서 · 판매 승인 전 · 실제 고객 배포 금지**

## 이 프로그램이 하는 일
받은 HTML 파일 한 개를 컴퓨터에서 직접 열어 상품·품목·사무실 목록을 검색, 분류, 정렬하고 상세정보를 조회합니다. 기본적인 조회에 별도 설치, 서버, 회원가입이나 인터넷 연결이 필요하지 않습니다. 제공되는 테마는 카페·재고·사무실 중 주문 시 승인된 하나입니다.

## 사용 방법
1. 전달받은 HTML 파일을 별도 폴더에 보관하고 Windows Chrome 또는 Edge에서 두 번 클릭해 엽니다. 상단 주소가 `file:///`로 시작하는지 확인합니다.
2. 검색창, 분류 필터, 정렬 기능을 이용합니다. 목록의 한 항목을 누르면 상세가 표시됩니다.
3. 나중에 CSV를 수정했다면 **CSV 파일 변경**을 눌러 새 CSV를 선택합니다. 기존 CSV와 **컬럼 이름이 같아야** 하며, 컬럼 순서만 다른 것은 허용됩니다. 항목 번호는 중복되면 안 됩니다.
4. 갱신이 실패하면 화면에 오류가 표시되고 이전 데이터는 유지됩니다. 원본 CSV와 원본 HTML 자체는 변경하지 않습니다.
5. 갱신된 내용을 다음에도 사용하려면 반드시 **변경 내용 HTML로 저장**을 눌러 새 HTML 파일을 다운로드합니다. 다음부터 새로 저장된 HTML을 열어야 합니다. 오래된 HTML을 열면 오래된 데이터가 나옵니다.

## 한계와 안전 주의
- 파일 크기 10 MiB 이하, 데이터 10,000행 이하, 컬럼 20개 이하, 셀당 2,000자 이하의 UTF-8 CSV만 지원합니다.
- 조회 전용입니다. 웹페이지에서 직접 셀을 고치거나 데이터를 서버에 자동 저장·동기화하지 않습니다.
- **HTML 내부 데이터는 평문**이므로 HTML을 타인에게 공유하면 기록도 함께 공개될 수 있습니다. 개인정보·암호·민감한 업무기밀을 넣지 마세요.
- 로그인, 접근권한 관리, 암호화, 서버 백업, 모바일 QR 접속, 클라우드 동기화, 자동 CSV 감시는 제공되지 않습니다.
- 브라우저 보안 또는 환경 설정으로 다운로드가 차단되면 브라우저의 저장 허용 상태를 확인합니다. 문제가 지속되면 승인된 지원 채널을 사용합니다(지원 채널은 미정).

## 검수 체크 항목
카페/재고/사무실 중 해당 HTML이 열리는가? 검색·분류·정렬·상세정보가 작동하는가? 잘못된 CSV로 기존 항목이 보존되는가? 올바른 CSV로 갱신되는가? 저장한 새 HTML을 닫고 다시 열었을 때 갱신 기록이 남아 있는가? 결과는 실제 고객 PC와 브라우저 버전, 실행 소요시간과 함께 기록합니다.
